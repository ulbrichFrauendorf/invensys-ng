Use in your application

The shell adds no content padding. Each routed page chooses its spacing. This component uses --page-layout-padding and --page-layout-sidebar-width; other pages can use their own styles. The mobile breakpoint matches the application navigation at 991px.

Sidebars slide down to hide and back up to return. Collapsing is enabled by default for either position. Use [(sidebarVisible)] to bind visibility, (sidebarVisibleChange) to react to changes, or call hideSidebar(), showSidebar(), and toggleSidebar() from an event handler. Set [sidebarCollapsible]="false" to keep the sidebar expanded. Hidden content keeps its selection and scroll position.
